# ApolloHealth

iOS app that helps users find free and low-cost healthcare clinics near them across the U.S.

**Winner, 2024 Congressional App Challenge (WI-03)**

Download: [App Store](https://apps.apple.com/us/app/apollohealth-find-a-clinic/id6740180697) · [Google Play](https://play.google.com/store/apps/details?id=com.apollohealth.sehatapp)

## Features

- Finds nearby clinics using the user's location
- Database of 11,000+ free and low-cost medical, dental, and behavioral health clinics
- Available in English, Spanish, and Hmong

This repository contains the iOS version; the Android version is available on Google Play.

Developed by Ali Abidi.
